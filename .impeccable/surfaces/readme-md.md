# Profile README

Visitor mode: Experience. Audience: someone opening github.com/kiet08hogit. Job: recognize Kiet and scan the work. Action: open the portfolio, GitHub, LinkedIn, or email. Proof: résumé facts only. Constraint: GitHub markdown and SVG, no page JavaScript.

## Direction contract

THESIS: A profile that reads like a typeset log of shipped work, opened by a city seen from the tracks. It refuses the badge wall, the emoji intro, and the moonlit ocean.

OWN-WORLD: Transparent ground so GitHub's own canvas shows through. Ink #37352f, muted #67635b, faint grid #b7c0ca, hairline #d8dee4, one rust #994509. Dark swaps to #e6edf3, #8b949e, #4b5563, #30363d, and #e09a55. JetBrains Mono, embedded, for every graphic. Hairline section labels. Project blocks are a name, an optional role, one sentence, and a stack line.

STORY: The visitor sees the train and the street grid, then the name, then five pieces of work, then a year of days as characters. They leave through the link row or a project link.

FIRST VIEWPORT: A 760 by 380 ASCII scene, centered. Skyline on the horizon, two rails, one rust train crossing, a street grid below. Under it, centered: "kiet ho", the tagline, the link row. About begins left-aligned beneath that.

FORM: Brief-pinned canon, Matthew Kim's profile README, with the hero subject replaced. No concept-seed roll; the user named the reference and asked for a different scene. Position: the reference's structure, first and only, because the request was to match that vibe.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.
